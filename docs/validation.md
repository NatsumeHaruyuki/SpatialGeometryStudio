交互路径：生产页面 → 画布拾取 A → 创建中点 Q → 撤销/重做 → 辅助线 AC → 拒绝永久共线截面 → 90° 二面角 → 动点端点与播放 → 中文路径保存/PNG → 120° 斜三棱柱 → 三棱锥顶点编辑 → 五棱锥 → 重开文件 → 拒绝无效文件 → 动态截面暂时退化、保存重开、恢复 → JSON 导入标为未保存。

最终便携产物检查：将实际 portable EXE 复制到“中文 便携运行”目录，在 PATH 只保留 Windows System32、移除外部 Electron 路径和开发服务器变量后启动。页面从 `app.asar` 加载，确认使用随包运行时；数据目录位于便携 EXE 旁。断网下运行 120° 二面角、动点至端点和数据目录 IPC，均无渲染错误。ZIP 内容与 7 个公开文件白名单完全相同；特意放入试用数据目录的 canary 文件未进入压缩包。此检查不代替另一台无开发环境电脑的实机验收。

实际便携版截图：`portable-preview.png`；设计参考：`design/workbench-concept.png`。实际便携截图和设计参考已在同轮 `view_image` 直接检查。窗口内容尺寸为 1466×922，另以浏览器检查了参考原生尺寸 1568×1003。

## 代码复查修正

- 发布 ZIP 使用明确的 7 个文件白名单，保留试用目录中的已有项目，但不将它们收入 ZIP。
- 粘贴 JSON 的场景标记为未保存；相机单独变化同样触发未保存状态。
- 拒绝重复面、断开的片面、自交面边界、非闭合及非凸多面体。
- 动点到达退化位置时保留动点参数，隐藏暂时未定义的截面并提示原因。新建动态截面存储有效的动点参数作为恢复依据；覆盖多个动点同时重合的回归场景。
