# 教学工具 v0.2 设计

沿用 Windows Electron/React/Three.js 工程和现有 UI；实现用户的五项修改，保持现有 .gscene v1 文件兼容，不修改外层原始材料，不安装新软件。如需安装软件，仍使用 D:\DevDep 下 camelCase 软件目录。

1. 工具栏增加“调整顶点”。屏幕平面拖动原始点；棱柱底点连同对应顶点变化，上层点平移上底；四棱锥基点约束在底面，锥顶自由。圆柱/圆锥通过原点、轴端和圆周控制点改变位置、高度、轴向和半径。一个拖动可一次撤销。保持有效几何，拒绝退化/非凸结果。
2. 球的定义已询问用户，等待其确定；空间三点不能唯一确定球，不用错误数学实现三点球。相关 UI/算法须采用用户回复的定义。
3. 所有截面支持 Alt+左键拖动，沿法向平移。三点截面新增可选 offset，保留依赖点；自由截面为 planeSection(origin,normal)。平移值保存并可撤销，离开立体时仍保留可拖动的截平面。
4. 模型库分类：棱柱→三棱柱、四棱柱；棱锥→三棱锥、四棱锥；圆柱；圆锥→单圆锥、双圆锥。旧样题文件仍可打开。旋转体使用解析参数，双圆锥为共顶点、方向相反的两锥；解析采样生成圆锥曲线，正确区分退化截面。提供截面类型预设、倾角和位移控制。
5. JSON 窗口增加“一键复制 Prompt”，桌面通过最小 clipboard IPC 复制完整内置提示词，网页预览用 Clipboard API。提示词与新增 schema 同步更新，用户可复制后在外部多模态 Agent 粘贴图片使用。

扩展 Scene v1：solid.primitive?:{kind:cylinder|cone|doubleCone,origin:Vec3,axis:Vec3,radius:number,height:number}；旋转体的 points 为软件计算的控制点，edges/faces 可为空。新增 planeSection；section.offset 可选。其余老数据不变。解析旋转体不冒充凸多面体，双锥不用凸包连接两锥。

验证：独立数学期望的几何单测、无效输入、拖动撤销/保存、截面四类型、Prompt 剪贴板全文、所有模型加载、Electron 离线交互、便携 ZIP 白名单与实际 EXE 启动。保留上一版发布物，v0.2 重新打包到新的版本目录。
