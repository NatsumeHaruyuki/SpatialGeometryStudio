# 四点二面角

用户已选择并要求直接实现：先选公共直线的两个端点 A、B，再选 P、Q，测量 P—AB—Q。替换工具原来的选两个实体面的操作。

- 工具启动提示“第 1 步：选择公共直线”，选够两个不重合点后提示“第 2 步：选择两个点确定两个平面”。蓝色表示 A、B 和公共直线，橙色表示 P、Q。画布和名称按钮保持一致。
- A、B 可为任意可用点，不要求是模型原有棱。第三点后显示第一个平面的预览，第四点后自动生成二面角，保留公共线、两个平面及角弧。
- 按两个点所在的半平面计算 0°–180°，保留钝角；点落在公共直线上时拒绝该次选取，保留前面的有效步骤。可取消、撤销、重做。
- 新构造保存为 `kind: dihedral, points: [A, B, P, Q]`，使用现有依赖链。旧 `faceA/faceB` 文件继续读取与显示。运动造成临时退化时显示原因，恢复后重现。
- 方案比较：用户选择公共直线四点方案；两条不同棱各配一点需要另求交线；原选面方案不能定义辅助平面。本次不增加额外模式切换。
- 颜色、预览样式由实现决定，使用现有 React / Three.js / Zustand 结构，无新增依赖。在原目录修改并重建 Windows v0.2 启动入口使用的 dist。
