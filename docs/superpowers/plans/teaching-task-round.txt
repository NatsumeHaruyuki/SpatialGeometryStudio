Export type RoundPrimitive={kind:'cylinder'|'cone'|'doubleCone';origin:Vec3;axis:Vec3;radius:number;height:number}. origin is base center for cylinder, apex for cone/doubleCone; axis points from origin to the first base cap for cone, from first base to second base for cylinder. Double cone has two opposite nappes with shared apex, each height h/radius r; never convex-hull the two.
Export roundFrame(p):{u:Vec3;v:Vec3;axis:Vec3}, with world=origin+u*x+axis*y+v*z, axis normalized. For axis=[0,1,0], prefer u=[1,0,0], v=[0,0,1].
Export roundControlPoints(p):Point[]. Cylinder: O origin,T top center,A base+u*r,B base+v*r,C base-u*r,A1 top+u*r. Cone: O apex,T cap center,A cap+u*r,B cap+v*r,C cap-u*r. DoubleCone: those plus T2 opposite cap center,A2 opposite cap+u*r,B2 opposite cap+v*r. Labels O/T etc, subscripts Unicode for 1/2; IDs ASCII.
Export moveRoundControl(p,id,desired:Vec3):RoundPrimitive: O translates origin; T changes axis and positive height, T2 uses opposite; ring points set perpendicular distance to axis as radius. Reject zero axis/height/radius and nonfinite/extreme values.
Export sectionRound(p,origin:Vec3,normal:Vec3):{curves:Vec3[][];closed:boolean[];kind:string;area:number|null}. Use analytic plane/implicit surface intersection, not faceted cone clipping. Cones x²+z²=(r/h)²y² in local frame. Sample continuous branches with finite-height clipping; avoid joining across singular denominators. Classification correct circle/ellipse/parabola/hyperbola, plane-through-apex degeneracies, and cylinder vertical/tangent/no-intersection cases. Kind strings Chinese (圆/椭圆/抛物线/双曲线/相交直线/一点/两条平行线/一条直线/无交线, as appropriate). Areas only when a real closed polygon/curve cross-section is represented; null for open/clipped conic branches. Cap boundaries are optional but do not invent closed areas from open branches. Curve sampling enough for smooth UI without excessive workload.
