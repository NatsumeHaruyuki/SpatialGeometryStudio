- Do not overwrite user data, existing releases or the remote initial commit.
- Keep macOS application data outside the .app bundle.
- Deliver native arm64 macOS for the user's confirmed Apple Silicon Mac; retain unverified Intel/Universal build commands and accurately state signing limits.
