# v0.2 Distribution Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Publish complete v0.2 source and deliver independently runnable Windows and macOS folder distributions.

**Architecture:** Keep the existing React/Three.js/Electron app. Wrap electron-builder unpacked output with samples, platform instructions, a version manifest and checksum. Test the relocated archive using its embedded Electron runtime; build Mac architectures on native Actions runners.

**Tech Stack:** TypeScript, Vitest, Electron 45, electron-builder 26, Node.js 24, GitHub Actions, Playwright CDP.

**Spec:** docs/superpowers/specs/2026-11-22-v0.2-distribution-design.md

## Global Constraints

- Keep v0.2 functionality and package version 0.2.1.
- No runtime dependency on development paths, Node.js or Python for the recipient.
- Do not overwrite user data, existing releases or the remote initial commit.
- Keep macOS application data outside the .app bundle.
- Build arm64 and x64 macOS packages on native runners; accurately state signing and validation limits.

## Review Focus

- Relocated Chinese paths and spaces: launch the extracted binary with a system-only PATH.
- Read-only application locations: retain the existing data fallback test.
- macOS bundle integrity: test data root outside .app, preserve relative symlinks and verify architecture.
- Distribution contamination: inspect archive entries for user data, development sources and caches.
- Offline operation and bundled Prompt: exercise the real packaged application with browser networking disabled.
