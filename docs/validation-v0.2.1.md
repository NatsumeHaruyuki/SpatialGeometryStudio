# v0.2.1 四点球验证

日期：2026-11-21。用户确认四个不共面点确定四面体，补齐外接球/内切球；此前四项修改继续保留。

- 9个Vitest文件、96项测试通过，包含12项纯球数学与6项球状态/依赖测试。验证已知直角/正四面体、24种顶点顺序、球心/半径、到四面的距离、极端尺度/平移及退化输入。
- TypeScript、Vite、Electron main/preload构建通过。
- Chrome/Electron交互共31组通过：原12组、教学工具7组、拖动回归6组、球工具6组。
- 实际球交互覆盖：共面初选拒绝；前三点不创建、第四个画布拾取完成；两球共存；源顶点变化；撤销/重做；删除；原生IPC保存/重开；PNG导出；动点重合时暂不可定义、JSON往返、恢复；2×10⁻⁵小四面体创建和重开渲染。
- 完整Prompt通过原生OS剪贴板精确全文对比，已包含两种球的四点定义与严格JSON字段；复制不会修改项目JSON。
- 独立复查已完成。发现的小尺度切点渲染判据不一致问题，已按球的归一化坐标直接计算radiusPoint；实际回归先失败、修复后通过，限定复核没有遗留Important/Critical问题。
- 视觉检查实际双球窗口：蓝色外接球、金色内切球、球心/半径文字分开显示，右侧列出半径、球心和所选四面体。截图：spheres-v0.2.1.png。Browser插件未提供，使用已有Chrome与Playwright/Electron，没有下载新浏览器。

便携包验证通过：从含中文和空格的目录启动实际EXE，PATH仅有System32，移除外部Electron路径，页面从包内app.asar加载、无Node require。离线验证120°二面角、四种圆锥曲线预设、四点双球的球心和半径、内置Prompt复制、数据目录IPC。测试结束关闭自己的独立窗口。
