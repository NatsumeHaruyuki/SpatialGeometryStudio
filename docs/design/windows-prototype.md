# Windows 试样范围与界面

依据外层 `reamde.md`，先制作 v0.1 Windows x64 便携试样，供实际操作评估。沿用指定的 Electron、React、TypeScript、Vite、Three.js、Zustand、Zod 和 Vitest；不修改外层需求和样题原件。

## 首版可操作范围

- 正方体、三棱锥、斜三棱柱及用户第 4 题的动点模型。
- 旋转、缩放、平移；选点、选面；中点、辅助线、三点截面、公共棱二面角。
- 棱上动点与依赖构造更新、暂停/播放、撤销/重做。
- `.gscene` / JSON 校验、保存、打开；PNG 导出；视角和显示设置随项目保存。
- 便携数据目录及不可写时的用户目录回退；只允许受限文件 IPC。
- AI 识图说明真实可用性，不伪造识别结果或外发用户材料。

## 参考设计

`workbench-concept.png` 由内置 ImageGen 生成，作为实现参考。实际的点线面与截面均由代码实时计算绘制，不使用该图作为界面或数学模型。

- 左侧深蓝模型库 230px，中部浅灰蓝画布，右侧白色属性栏 300px。
- 顶部项目操作；浮动构造工具栏；底部动点条及状态栏。
- 背景 #f5f8fb、面板 #ffffff、侧栏 #142635、强调 #167d83、次要文字 #6e7d89。
- Segoe UI / Microsoft YaHei；标题 22px，主体 14px，工具按钮 13px，公式 Georgia；8px 圆角、细边框、克制阴影。
- 线性 SVG 图标，中点、辅助线、截面和二面角各有独立图形。
- 窄窗口缩减边栏宽度，工具可横向滚动；Windows 主交互以桌面尺寸为准。

实际功能需要的补充：撤销/重做、样题提示、项目设置及 PNG 导出入口。不得将不完备题目的示意参数称为唯一解；斜三棱柱使用满足所给关系的一组坐标，并注明取值。

## 验证

先以独立数学期望测试截面（含过棱/过顶点/相切）、二面角、依赖及无效文件，再做 Three.js / Electron 交互、文件往返和便携 EXE 冒烟测试。真实无开发环境电脑、Windows 10 / MX250 等环境留给后续验收，不把开发机结果代替这些验收。

## 安装约定

新增外部软件放到 `D:\DevDep` 下对应的 camelCase 目录；Node.js 放 `D:\DevDep\nodeJs`，Electron 下载缓存放 `D:\DevDep\electron`，构建缓存放 `D:\DevDep\electronBuilder`，npm 缓存放 `D:\DevDep\npmCache`。项目代码、项目依赖、样例及发布物均留在本项目目录。
